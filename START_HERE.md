# 🚀 Старт с нуля — инструкция для тех, кто не программист

Этот файл — самая простая дорожка запуска проекта.
Читайте сверху вниз, копируйте команды по одной. Всё остальное в README — справочник.

---

## Шаг 1. Установите две программы на свой компьютер

| Программа | Зачем | Где взять |
|---|---|---|
| **Git** | скачать проект | https://git-scm.com/downloads (кнопка Download, дальше везде «Далее») |
| **Docker Desktop** | запустить базу данных и сайт одним кликом | https://www.docker.com/products/docker-desktop/ (для Windows/Mac) |

После установки **перезагрузите компьютер** и запустите Docker Desktop
(в трее должен появиться кит 🐳). Git для способа А не нужен — только Docker.

> Linux вместо Docker Desktop: `sudo apt install docker.io`

## Самый простой способ (рекомендую) — один файл, без Docker

Никакого Docker не нужен. И даже Python ставить не обязательно: скрипт сам
скачает компактный встроенный Python при первом запуске (ты увидишь прогресс-бар).

1. Открой страницу релизов:
   https://github.com/sinor-pomidor/tgu-navigator/releases
2. В самом верхнем релизе (v0.2.5) скачай файл **tgu-navigator-0.2.5.zip**.
3. Распакуй архив в любую папку (например, на Рабочий стол).
4. Двойной клик по файлу:
   - **Windows** → `run.bat`
     (если спросит «Запустить в любом случае» через SmartScreen — нажми «Подробнее» → «Выполнить»)
   - **Mac / Linux** → в терминале: `cd <папка>` затем `./run.sh`
      (если пишет «нет прав»: сначала выполни `chmod +x run.sh`)
5. Первый запуск займёт 3–8 минут: ты увидишь шаги и прогресс-бары загрузки —
   это нормально, компьютер работает, а не завис. Потом браузер
   сам откроет страницу:

   **http://localhost:8000**

Всё, можно пользоваться как веб-приложением. Никаких ключей и паролей не нужно.
Данные сохранятся в папке `data/` внутри проекта — между запусками ничего не теряется.

Если Windows спрашивает разрешение на доступ — нажми «Разрешить».
Если браузер не открылся сам — просто открой ссылку выше вручную.

Остановка: закрой чёрное окно «TGU Navigator - сервер» (Windows) или выполни
`./run.sh stop` (Mac/Linux). Следующие запуски будут быстрыми — просто двойной клик.

## Шаг 2. Скачайте проект

Откройте терминал:
- **Windows**: меню Пуск → напишите `cmd` → Enter
- **Mac**: Cmd+Пробел → напишите `Terminal` → Enter

Введите команду (один раз) и нажмите Enter:

```bash
git clone https://github.com/sinor-pomidor/tgu-navigator.git
cd tgu-navigator
```

Готово — проект у вас на компьютере.

## 🟢 Самый простой путь: установочный скрипт (рекомендую)

В папке проекта есть файлы **install.bat** (Windows) и **install.sh** (Mac/Linux).
Они делают ВСЕ шаги ниже сами: проверяют Docker, создают настройки,
запускают базу данных и сайт, загружают каталог возможностей.

- **Windows**: откройте папку `tgu-navigator` в проводнике и дважды
  кликните по **install.bat**. Дождитесь надписи «ПРОЕКТ УСТАНОВЛЕН» —
  браузер сам откроет страницу http://localhost:8000/
- **Mac/Linux**: в терминале выполните две команды:

```bash
cd tgu-navigator
./install.sh
```

Если скрипт ругается на Docker — значит Docker Desktop не запущен:
откройте его, дождитесь зелёного статуса и запустите скрипт снова.

Дальше можно ничего не читать — проект работает. Остальные шаги —
«ручная» версия того же самого, если захотите понимать, что происходит.

## Шаг 3. Поднимите базу данных

В том же окне терминала:

```bash
docker compose up -d db
```

Ждите 20–40 секунд. Проверьте, что база готова:

```bash
docker compose ps
```

В столбце STATUS должно быть написано `healthy` (не `starting`).

---

## Шаг 4. Наполните базу данными

Скачаем готовый список возможностей ТГУ в базу:

```bash
docker compose exec app python -m app.seed
```

Если команда выше ругается (контейнер `app` ещё не поднят) — используйте этот вариант:

```bash
docker compose run --rm app python -m app.seed
```

Увидите строчки вида `Загружено 22 возможностей` — успех ✅

## Шаг 5. Запустите сайт-API

```bash
docker compose up -d app
```

Проверка, что всё живое — откройте в браузере:

| Ссылка | Что увидите |
|---|---|
| http://localhost:8000/health | `{"status":"ok"}` |
| http://localhost:8000/docs | интерактивная страница, где можно тыкать кнопки «Try it out» |
| http://localhost:8000/opportunities | JSON со всеми 22 возможностями |

На странице `/docs` выберите **POST /ask** → Try it out → впишите
`{"query": "хочу в проект по ИИ"}` → Execute. Система вернёт подборку.
Это уже работает без Telegram.

## Шаг 6 (по желанию). Подключите Telegram-бота

### 6.1 Получите токен за 2 минуты
1. В Telegram найдите контакт **@BotFather** (с галочкой).
2. Отправьте ему команду `/newbot`.
3. Он спросит имя бота — напишите любое, например: `ТГУ Навигатор`.
4. Потом спросит username — придумайте окончание `bot`, например: `tgu_navigator_demo_bot`.
5. BotFather пришлёт длинную строку вида `7123456789:AAH...abc` — **это токен**. Скопируйте его.

### 6.2 Сохраните токен в файл .env
В терминале (из папки проекта):

```bash
cp .env.example .env
nano .env
```

Откроется редактор в терминале. Найдите строку:

```
TG_BOT_TOKEN=
```

и после знака `=` вставьте скопированный токен, чтобы получилось так:

```
TG_BOT_TOKEN=7123456789:AAH...abc
```

Сохраните: **Ctrl+O**, Enter, выйти: **Ctrl+X**.
(В Windows вместо nano можно открыть файл блокнотом: `notepad .env`)

⚠️ Файл `.env` никуда не отправляйте и не выкладывайте — он только для вас.

### 6.3 Запустите бота

Бот запускается отдельной командой (он не входит в docker-compose):

```bash
python -m app.bot.bot
```

Если пишет `No module named 'aiogram'` — сначала один раз установите зависимости:

```bash
pip install -r requirements.txt
```

Если в консоли появилась строчка про запуск бота — всё хорошо,
окно не закрывайте (бот работает, пока окно открыто).
Остановить бота: **Ctrl+C**.

> Продвинутый вариант без второго окна: `docker compose exec app python -m app.bot.bot`

### 6.4 Попробуйте
Найдите своего бота в поиске Telegram (`@tgu_navigator_demo_bot`),
нажмите Start и напишите: `интересуюсь ИИ, хочу в проект`.

## Частые проблемы

| Симптом | Решение |
|---|---|
| `docker: command not found` | Docker Desktop не запущен или компьютер не перезагружен после установки |
| `address already in use :5432` | У вас уже стоит PostgreSQL. Освободите порт или измените его в docker-compose.yml |
| `address already in use :8000` | Порт занят. Закройте другую программу или поменяйте `8000:8000` на `8081:8000` в docker-compose.yml |
| Бот молчит | Проверьте токен: `docker compose logs bot` — там будет подсказка |
| `connection refused` при запросе к базе | База ещё не поднялась: подождите и повторите `docker compose ps` |

## Остановить всё

```bash
docker compose down
```

Данные при этом сохраняются. Чтобы удалить данные совсем:
`docker compose down -v`
